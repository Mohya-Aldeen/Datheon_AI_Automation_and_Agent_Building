# Blueprints

Put the exported Make scenarios here:

- `scenario-a-lead-intake.blueprint.json` (Webhook, OpenAI, Airtable, Slack)
- `scenario-b-tally-translator.blueprint.json` (Tally webhook, HTTP)

How to export: open the scenario in Make, click the three dots (More) in the
bottom toolbar, then **Export Blueprint**.

Before committing, open each file and check for webhook URLs, emails and tokens.
